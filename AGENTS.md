# AGENTS.md

## Project Overview
This is a personal portfolio website for a full-stack developer.

The goal is to build a modern, production-ready developer portfolio that showcases:
- Projects
- Skills
- Experience
- Contact info

This is NOT a demo or toy project. Code quality and structure must be professional.

---

## Tech Stack
- Frontend: Vue 3 + Vite
- Styling: Tailwind CSS
- Routing: Vue Router
- Language: JavaScript (ES6+)

---

## Design Requirements
- Style: Modern, minimal, tech-focused (dark theme preferred)
- Primary color: #4B7BFF
- Responsive design (mobile + desktop)
- Clean layout, NOT cluttered
- Smooth hover animations

---

## Project Structure

src/
  components/
  views/
  router/
  assets/

Pages:
- Home
- About
- Projects
- Contact

---

## Coding Rules

### MUST DO
- Use composition API
- Use functional, reusable components
- Keep components small and modular
- Use Tailwind for ALL styling (no inline styles)
- Use semantic HTML

### MUST NOT
- Do NOT use Vue 2 syntax
- Do NOT mix multiple styling systems
- Do NOT hardcode large data inside components (use JSON if needed)

---

## Component Rules

- Navbar must be reusable
- Project cards must be reusable
- Layout must be consistent across pages

---

## Output Expectations

When generating code:
- Always provide COMPLETE files
- Do NOT give pseudo code
- Do NOT skip imports
- Code must be runnable

---

## Behavior

You are a senior frontend engineer.

- Think before coding
- Follow structure strictly
- Do not invent random architecture
- Prioritize readability and maintainability
